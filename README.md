# SimuMina CAEX · demo web

**Abrir la demo:** https://jmhuamann-bit.github.io/simumina/

Demo del simulador SimuMina para operadores de camiones mineros (CAEX): falla del freno de servicio bajando cargado por una rampa, con tutor de IA y reportes de Seguridad y Salud Ocupacional (SSO).

- Se maneja con el teclado: en la portada, **Demostración rápida con teclado**. `W` acelera, `A` `D` giran, `Espacio` retardador, `B` freno de emergencia, `R` (mantener) radio.
- Los registros y reportes que trae son de demostración (operadores ficticios). Lo que haga cada visitante queda solo en su navegador.
- En la estación de la mina, la misma plataforma conecta el visor de realidad virtual, el volante con pedales y el traje háptico.

Esta página se genera con `npm run demo-web` desde el proyecto SimuMina. three.js (licencia MIT) se carga desde jsDelivr.
